# Sophon Downloader

A lightweight tool for downloading assets from <i>**a specific anime game**</i> using the Sophon-based content delivery system.


## Requirements

- Windows x64
- Install <i>[.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)</i>


## Compile Instructions

To compile the project:
1. Run `compile.bat`
2. The release output will be generated automatically inside the `bin` folder
